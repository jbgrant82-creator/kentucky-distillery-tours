# Kentucky distillery tours

Interactive scatter plot of distillery tour quality against drive time from Versailles, KY.

Open the live page: https://jbgrant82-creator.github.io/kentucky-distillery-tours/

Composite tour score (0-100) blends volume-weighted Google, TripAdvisor and Yelp ratings (70%) with editorial, awards and media recognition (30%). Methodology and sources are documented on tabs within the page itself.
